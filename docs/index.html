🔌 Klient, kanál a zvuk

Zvukové efekty (ES8311 syntezátor)
Tip: Můžete klikat i přímo do displeje na dotyková tlačítka, na chatovací okno pro zvětšení, na maskota, nebo nahoře na fyzická tlačítka. BOOT přepíná obrazovky Akce, Profil a Info, IO18 posouvá historii zpráv. Při dotazu se dvěma volbami BOOT volí první a IO18 druhou možnost, u 3 a více voleb BOOT posouvá výběr a IO18 ho potvrdí, dotykem první klepnutí volbu vybere a druhé ji odešle. Rizikový příkaz se schvaluje podržením SCHVÁLIT nebo BOOT po dobu 1 s. Prvních 0,7 s po objevení dotazu tlačítka nereagují, aby klepnutí mířené jinam nic neschválilo. U AGY karta ukazuje, kolik času zbývá. V menu BOOT posouvá položky a IO18 vybírá.
FILOZOFIE PROJEKTU

Proč Rozhodovač místo Schvalovače?

Proč původní schvalování každého souboru v éře autonomních AI agentů nedává smysl.

Starý způsob: Schvalovač

Tupá stopka u každého zápisu

Agent běží v poloautomatickém režimu a při každém vytvoření souboru nebo spuštění git status zastaví a čeká na kliknutí.

  • ❌ Neustálé vyrušování u rutinních a bezpečných akcí
  • ❌ Brzdí plynulý tok myšlenek i rychlost vývoje
  • ❌ Člověk tlačítko mačká slepě bez čtení
Moderní způsob: Rozhodovač

Autonomie + cílené rozhodování

Agent dělá běžnou práci zcela automaticky. Rozhodovač slouží jako živý monitor na stole a vzbudí vás pouze tehdy, když je to nutné.

  • ✅Běžná rutina krabičku nezastaví, rozhoduje o ní vaše nastavení AGY
  • ✅Otázky agenta (ask_question): 2 až 8 možností přímo na dotykových tlačítkách, zvolenou odpověď dostane agent
  • ✅Claude Code v terminálu: žádosti o povolení i otázky, také několik po sobě a s vícenásobným výběrem, odpovíte na krabičce se stejnými volbami jako v terminálu
  • ✅Záchranná brzda: chytá destruktivní příkazy (git push -f, rm -rf, Remove-Item -Recurse, drop table a další) a ukáže skutečný příkaz, ne popis od agenta. Schvaluje se podržením, omylem klepnutím to nejde
  • ✅Bezpečné spojení: daemon se připojuje jen ke své spárované krabičce a lokální rozhraní chrání token, takže jiný program ani cizí krabička v dosahu nic neschválí

decide DOPORUČENO

Výchozí režim Rozhodovače. Běžné čtení i zápisy souborů krabičku nezastaví. Dotyk vyžaduje jen u otázek s volbami (2 až 8 možností) a u destruktivních příkazů.

write STRIKTNÍ

Schvalování všech zápisů a spouštění skriptů. Vhodné pro citlivé produkční repositáře, kde chcete vidět každý změněný soubor.

all AUDIT

Úplné zastavení i u operací čtení a webového vyhledávání. Vhodné pro detailní bezpečnostní audit jednotlivých kroků.

OBRAZOVKY FIRMWARU

Jak Rozhodovač vypadá

Rendery krabičky Waveshare ESP32-S3-Touch-AMOLED-2.16 podle rozměrového výkresu výrobce: bílé pouzdro 46 × 46 × 22,5 mm, tři tlačítka nahoře. Obrazovky jsou vykreslené stejným písmem, barvami a rozvržením jako ve firmwaru.

1. Hlavní obrazovka s Claude Claude Desktop pracuje: štítek CLAUDE·BLE, počet běžících relací, baterie, přemýšlející Clawd a historie akcí, nejnovější nahoře.
2. Schválení příkazu z Claude Claude Desktop přes Bluetooth žádá o schválení vynuceného pushe, krabička běží na baterii. Rizikový příkaz pozná sama, proto se SCHVÁLIT musí podržet. Claude čas na odpověď neposílá, karta ukazuje, jak dlouho dotaz čeká, a po 10 s rámeček zčervená.
3. Otázka z AGY Otázky s volbami posílá hook pro AGY, proto je tu Agy s vykřičníkem. Tady dvě možnosti na dotykových tlačítkách, případně BOOT a IO18; od 3 voleb jsou řádky pod sebou, od 5 voleb bez maskota. Vpravo nahoře zbývající čas, pak se otázka vrátí do terminálu. Zvolenou možnost dostane agent jako odpověď.
4. Stolní hodiny Krabička je připojená k AGY přes USB a agent zrovna nic nedělá. Při napájení z USB se po 20 s nečinnosti zobrazí jen velké hodiny s datem.
TECHNICKÉ PARAMETRY

Waveshare ESP32-S3-Touch-AMOLED-2.16

Výkonná embedded platforma s vysoce kontrastním kruho-čtvercovým displejem.

🖥️

2,16″ AMOLED Displej

Rozlišení 480 × 480 px, QSPI řadič CO5300, hluboká černá AMOLED panelu. Firmware kreslí do 16bitového (RGB565) framebufferu v PSRAM.

⚡

ESP32-S3 Dual-Core

240 MHz Xtensa LX7 (se zhasnutým displejem 80 MHz kvůli baterii), 16 MB Flash paměť, 8 MB Octal PSRAM pro plynulý 480×480 frame buffer v RAM.

👆

Kapacitní dotyk CST9220

Citlivé dotykové ovládání, podpora gest (swipe vlevo/vpravo/nahoru/dolů) i detekce přikrytí dlaní.

🔋

Napájení & PMU AXP2101

Správa Li-Ion baterie: procenta z měřidla PMU, napětí a teplota, detekce USB VBUS a nabíjení, varování při 20 a 10 %. Tlačítko PWR zhasíná displej.

🔊

ES8311 I2S Audio Kodek

Vestavěný reproduktor: rozlišené zvuky pro otázku, rizikovou akci, dokončení práce, připomínky a slabou baterii. Hlasitost ve třech úrovních a noční klid, zesilovač i kodek běží jen během melodie.

🕒

RTC PCF85063 Hodiny

Zálohovaný reálný čas pro velké stolní hodiny HH:MM:SS a kalendář i při odpojení od počítače.

🧭

6-osá IMU QMI8658

Akcelerometr a gyroskop: zatřesení krabičkou zamotá maskotovi hlavu, otočení displejem dolů ho uspí.

📡

USB-C & Bluetooth LE 5

Priorita po kabelu (USB CDC), bezdrátové přepnutí na Bluetooth (NUS) na baterii a po zapojení kabelu zpět na USB. Šifrované párování s PINem, krabička si pamatuje až 3 počítače.

PRŮVODCE ZAPOJENÍM

Jak začít během 2 minut

Vše je připraveno pro snadné spuštění na Windows i dalších systémech.

Krok 1: Nainstalujte PlatformIO a knihovny mostu

Stačí Python 3.10 nebo novější. První build stáhne toolchain ESP32 (stovky MB) a trvá několik minut.

python -m pip install platformio pyserial bleak

Krok 2: Připojte krabičku k PC

Použijte kvalitní datový USB-C kabel. Krabička se v systému přihlásí jako sériové zařízení (např. COM8). Pokud krabičku ještě nemáte, pořídíte ji na RPishop.cz.

Krok 3: Spusťte flash skript

Skript zkompiluje firmware, uvolní port (zastaví jen daemon Rozhodovače) a nahraje firmware do ESP32-S3:

.\flash.ps1

Zapnutí integrace v Antigravity CLI

Můžete zapnout Rozhodovač globálně pro všechny vaše projekty v AGY:

python bridge/rozhodovac_ctl.py enable-global

Ověření stavu

python bridge/rozhodovac_ctl.py status

Kdo rozhoduje o běžné práci

U běžných nástrojů hook vrací AGY rozhodnutí allow, takže platí vaše nastavení oprávnění v AGY. Chcete-li, aby rutina běžela bez potvrzování, povolte v AGY automatické spouštění nástrojů. Co schválíte na krabičce, už se v terminálu znovu neptá. Když krabička neodpoví včas nebo je odpojená, rozhodne terminál. Dotazy z více relací AGY naráz krabička ukáže po sobě.

Propojení přes Bluetooth s Claude Desktop

1. Zastavte případný lokální daemon: python bridge/rozhodovac_ctl.py stop. Hooky ho pak samy nespustí, zapnete ho znovu příkazem start.

2. V aplikaci Claude Desktop otevřete: Developer → Open Hardware Buddy…

3. Vyberte zařízení Claude-XXXX a opište 6místný párovací PIN z displeje krabičky.

Rizikové příkazy z Claude (rm -rf, push --force, reset --hard…) krabička pozná podle textu a schvalují se podržením tlačítka.

Claude Code v terminálu

Claude Code spuštěný v terminálu aplikace Claude Desktop nevidí, krabičku obsluhuje most přes USB kabel (s balíčkem bleak i přes Bluetooth). Hooky zapnete pro všechny projekty:

python bridge/rozhodovac_ctl.py enable-claude

V nově spuštěném Claude Code pak krabička ukazuje zadání, spuštěné nástroje, začátek poslední odpovědi a tokeny. Žádosti o povolení a otázky, na které by se jinak ptal terminál, se nejdřív ukážou na krabičce se stejnými volbami: povolení i s „Ano, už se neptat“, otázky po jedné i s vícenásobným výběrem, tlačítky ZPĚT a DALŠÍ a na konci se shrnutím k odeslání. Tlačítko TERMINÁL vrátí dialog do terminálu. Když na krabičce nikdo do 30 s (u otázek 60 s na každý krok) nerozhodne, zeptá se terminál jako obvykle.

Testování a správa Rozhodovače

KOMPLETNÍ REFERENCE PŘÍKAZŮ

Příkazy rozhraní Rozhodovače

Všechny dostupné příkazy pro ovládání, přepínání režimů, testování a nahrávání.

Příkaz Kategorie Popis funkce
python bridge/rozhodovac_ctl.py status Diagnostika Zobrazí stav spojení (USB / BLE), % baterie, režim, statistiky rozhodnutí a parťáka.
python bridge/rozhodovac_ctl.py test-question Test Odešle na displej ukázkový dotaz s volbami (2 až 8 voleb, výchozí 3) pro vyzkoušení dotykového výběru i tlačítek BOOT/IO18.
python bridge/rozhodovac_ctl.py test Test Odešle na displej žádost o potvrzení kritické akce (git push --force). SCHVÁLIT se drží 1 s, ZAMÍTNOUT stačí klepnout.
python bridge/rozhodovac_ctl.py mode decide Režim Výchozí režim: Běžná rutina krabičku nezastaví, dotyk vyžaduje jen u otázek s volbami (2 až 8 možností) a rizikových akcí. Režim se uloží do bridge/state.json a platí trvale.
python bridge/rozhodovac_ctl.py mode write Režim Striktní režim: Vyžaduje potvrzení u všech zápisů do souborů i spouštěných příkazů.
python bridge/rozhodovac_ctl.py mode all Režim Auditní režim: Vyžaduje potvrzení u každého jednotlivého volání nástroje.
python bridge/rozhodovac_ctl.py enable-global Integrace Aktivuje Rozhodovač globálně pro všechny vaše projekty v AGY (~/.gemini/config/hooks.json).
python bridge/rozhodovac_ctl.py disable-global Integrace Deaktivuje globální integraci v AGY a vrátí standardní terminálové chování.
python bridge/rozhodovac_ctl.py enable-local Integrace Aktivuje Rozhodovač jen pro projekt v aktuální složce, nebo ve složce zadané přes --dir (.agents/hooks.json).
python bridge/rozhodovac_ctl.py disable-local Integrace Vypne Rozhodovač v projektu (aktuální složka nebo --dir). Ostatní hooky v hooks.json zůstanou beze změny, zapnutí globálně toto vypnutí nepřepíše.
python bridge/rozhodovac_ctl.py enable-claude Integrace Zapne Rozhodovač pro Claude Code v terminálu ve všech projektech (~/.claude/settings.json), s --dir jen v projektu (.claude/settings.local.json). Ostatní nastavení a hooky zůstanou beze změny.
python bridge/rozhodovac_ctl.py disable-claude Integrace Vypne Rozhodovač pro Claude Code v terminálu (bez --dir globálně, s --dir v projektu).
python bridge/rozhodovac_ctl.py start Služba Spustí obslužný background daemon (připojí se k USB CDC nebo BLE dle dostupnosti).
python bridge/rozhodovac_ctl.py stop Služba Zastaví background daemon (např. před párováním s Claude Desktop). Hooky ho pak samy nespustí, až příkaz start.
python bridge/rozhodovac_ctl.py name "Jméno" Přizpůsobení Nastaví vlastní jméno parťáka zobrazené v profilu na displeji.
python bridge/rozhodovac_ctl.py unpair Přizpůsobení Smaže v krabičce uložená Bluetooth párování, když se Claude Desktop nebo PC nechce znovu připojit. Ve Windows pak krabičku odeberte i v Nastavení → Bluetooth.
python bridge/rozhodovac_ctl.py forget-device Přizpůsobení Daemon zapomene zapamatovanou krabičku a příště se přes Bluetooth spojí s první nalezenou (při výměně krabičky).
.\flash.ps1 Firmware Zkompiluje a nahraje firmware do ESP32-S3 přes USB kabel. Před nahráním zastaví daemon, aby uvolnil port, a po chybě kompilace se zastaví.
.\flash.ps1 -Monitor Firmware Spustí sériový monitor pro sledování logů z krabičky v reálném čase.
